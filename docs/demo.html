DeepSeek Harness plugin

A ticket-first board where
agents do the work.

Plan with the agent, approve the plan, let workers execute in isolated Git worktrees, then review the diff, checks and transcript before merging. Humans keep the gates.

Take the 60-second tour View source

A board, not a chat

Every ticket is durable state. Columns are the real workflow: backlog, ready, in progress, review, done, blocked.

Plan gate

An agent explores and submits a plan with acceptance criteria. Nothing runs until a human approves it.

Isolated runs

Each run gets its own Git worktree and branch. Budgets, subagents and checks are recorded on the run.

Review gate

Diff, checks and the worker transcript in one drawer. Reject resumes the session; approve squash-merges.

Queue operations

Search, filters, saved views, batch select and a durable priority queue.

Automation, opt-in

Reviewer sessions, webhooks, PR mode, WIP limits — all off by default, all auditable.

Local-first

JSON, append-only journal or SQLite storage with a single-writer guard. No cloud required.

Try it

git clone https://github.com/HoomerPH/dsh-board.git ~/dsh-board
cd ~/dsh-board && scripts/install-profile.sh
cd /path/to/your/repo && dsh --profile board

Open the printed URL, click Board, then type /board <what you want built> in the chat. Requires DeepSeek Harness, Node.js ≥ 20, pnpm and Git.
